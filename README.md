🚀 Vedant Nayyar — Personal Portfolio Website
A personal, high-performance portfolio website built with modern HTML5, vanilla CSS, and JavaScript. Designed with a dark space-themed glassmorphism aesthetic, interactive particle engine, smooth scroll animations, and dynamic UI micro-interactions.

✨ Features
Interactive Particle Background: HTML5 Canvas-based background with dynamic node networking and responsive recalculation on viewport resize.

Custom Cursor & Interactive Orbits: Dual-ring custom cursor tracking with context-aware scaling on hoverable elements, accompanied by continuous orbiting tech-stack indicators.

Typing Terminal & Visual FX: Dynamic typewriter effect cycling through code snippets, paired with subtle text glitch effects.

Tilt & Scroll Animations: Interactive 3D tilt effects on project cards and scroll-triggered section entrance animations using IntersectionObserver.

Responsive Navigation: Mobile-friendly navigation drawer with active section highlight tracking based on scroll position.

Contact Form Validation: Interactive client-side contact submission simulation with status feedback.

🛠️ Tech Stack & Concepts
Frontend Core: HTML5, Modern CSS3 (Custom Properties, Flexbox, CSS Grid)

Scripting: Vanilla JavaScript (ES6+ Modules, Async/Timers)

APIs & Web Engines: HTML5 Canvas API, IntersectionObserver, requestAnimationFrame

Typography & Icons: Syne, Space Mono (via Google Fonts), FontAwesome Icons
